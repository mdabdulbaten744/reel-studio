## Motion language (mimic After Effects, in code)
Nothing moves linearly. Use ease-out for arrivals, ease-in for slams, overshoot/back for pops, expo for text reveals. Reveal headlines with a mask (clip) while the text slides up. Stamp/slam elements: large → impact → damped rebound, with a few pixels of decaying camera shake and a 1–2 frame flash. Scene changes: hard cuts on a beat, or 4-bar staggered colour wipes. Add subtle film grain, a soft vignette and stagger related elements by 30–60 ms. Keep important content inside the safe zone: y 260–1560, x 70–1010 (Instagram covers the rest).

## Sound (no voice-over, no music file)
Everything is synthesised with the Web Audio API inside an `OfflineAudioContext` (noise buffers, oscillators, filters, convolution reverb, compressor). Every visible beat has a sound: ticks on cuts (pitch rising with speed), thuds on stamps, whooshes on wipes, typewriter keys, mouse clicks, soft slider ticks generated by sampling the same value function that drives the slider, a chime on success. Peak below −2 dBFS, fade out the last 0.5 s. Sound events must read the same timeline constants as the visuals so sync is exact.

## Technical contract (the build breaks if any of this is missing)
- Single `.html` file, no other files. The only allowed network request is the Google Fonts stylesheet.
- A `1080×1920` element `#viewport` is the video frame. Everything visible lives inside it.
